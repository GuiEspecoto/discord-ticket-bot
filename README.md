
# 🎫 Discord Ticket Bot

> Bot para Discord desenvolvido em Python com foco em atendimento e gerenciamento de tickets.

Um sistema de tickets desenvolvido para facilitar o atendimento dentro de servidores Discord, permitindo organizar solicitações dos usuários através de canais privados e automatizados.

---

## ✨ Funcionalidades

- 🎫 Criação de tickets
- 🔒 Canais privados para atendimento
- 🛠️ Gerenciamento de tickets
- 📋 Organização das solicitações
- 💾 Armazenamento de estados e configurações
- ⚙️ Configuração personalizada
- 🤖 Automação de processos do servidor

## ⚙️ Configuração

### 1. Clone o repositório

```bash
git clone https://github.com/GuiEspecoto/discord-ticket-bot.git
```

### 2. Entre na pasta

```bash
cd discord-ticket-bot
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

### 4. Configure as variáveis do bot

Crie um arquivo `.env` na raiz do projeto e adicione as informações necessárias.

> ⚠️ Nunca publique seu `.env` ou o token do seu bot no GitHub.

### 5. Execute o bot

```bash
python bot.py
```

---

## 🔐 Segurança

Informações sensíveis, como:

* Token do Discord
* Chaves de API
* Senhas
* Credenciais

devem permanecer fora do repositório.

O arquivo `.env` é ignorado pelo Git através do `.gitignore`.
